Academic Research Project · Machine Learning

Context Aware Movie Recommender

A hybrid movie recommendation system that combines content-based filtering, collaborative filtering, and context-aware techniques to generate personalized recommendations. The system incorporates user preferences, mood, and real-time interactions, with a diversity-aware re-ranking mechanism to improve recommendation variety. Extended with Apache Spark for distributed processing of large-scale datasets (32M+ ratings across 87,600 movies), achieving Precision@10 of 0.318 and Genre Coverage of 10.1.

✦ Key Features
  • Hybrid scoring: content-based + collaborative filtering (ALS)
  • Context-aware: mood & time-of-day personalization
  • Diversity-aware re-ranking to avoid repetitive genres
  • Apache Spark for distributed big data processing
  • Explainability module with human-readable reasons
  • Real-time user profile updates on click/watch
  • Cold-start handling for new & returning users
  • Streamlit-based interactive web UI
✦ Results
  • Precision@10 = 0.318
  • Recall@10 = 0.187
  • NDCG@10 = 0.355
  • Genre Coverage = 10.1 (high diversity)
✦ Tech Stack
Python Apache Spark Scikit-learn Pandas NumPy Streamlit TF-IDF ALS (MLlib) Parquet MovieLens 32M

Academic Research Project · Machine Learning

VC-Dimension Aware Sentiment Analysis

A machine learning-based sentiment analysis system that investigates the relationship between model complexity and generalization using VC Dimension theory. The project evaluates Logistic Regression, SVM, and Decision Tree classifiers on IMDB and Twitter datasets, using TF-IDF feature space size as a practical proxy for complexity. An interactive Streamlit application enables real-time sentiment prediction and visualization of model behavior.

✦ Key Features
  • VC-dimension inspired complexity analysis using TF-IDF vocabulary size
  • Comparative evaluation of Logistic Regression, SVM, and Decision Tree
  • Sentiment classification for positive, negative, and neutral text
  • Multi-dataset experimentation on IMDB and Twitter reviews
  • Interactive Streamlit dashboard for prediction and comparison
  • Text preprocessing, normalization, and feature extraction pipeline
  • Visualization of accuracy trends and overfitting behavior
✦ Results
  • IMDB: Logistic Regression 90.03%, SVM 89.83%, Decision Tree 70.40%
  • Twitter: Logistic Regression 84.14%, SVM 85.36%, Decision Tree 48.61%
  • Logistic Regression showed stable generalization across feature dimensions
  • Moderate TF-IDF vocabulary sizes balanced accuracy and overfitting

Python Scikit-learn Streamlit Hugging Face Datasets TF-IDF Pandas NumPy Matplotlib Seaborn

Deep Learning Project · Predictive Analytics

Customer Churn Prediction Using Artificial Neural Networks

A deep learning-based customer churn prediction system designed to identify bank customers likely to discontinue services. The project uses demographic, financial, and account-related attributes to train an ANN that predicts attrition and helps financial institutions implement targeted retention strategies.

✦ Key Features
  • End-to-end churn prediction pipeline using Artificial Neural Networks
  • Automated preprocessing including encoding, scaling, and train-test split
  • One-Hot Encoding for categorical customer attributes
  • StandardScaler-based feature normalization for stable convergence
  • Multi-layer ANN with ReLU and Sigmoid activations
  • Binary classification for churn risk prediction
  • Evaluation using Accuracy, Confusion Matrix, and ROC-AUC
✦ Model Architecture
  • Input Layer: 11 Features
  • Hidden Layer 1: 16 Neurons (ReLU)
  • Hidden Layer 2: 8 Neurons (ReLU)
  • Output Layer: 1 Neuron (Sigmoid)
  • Optimizer: Adam
  • Loss: Binary Crossentropy
  • Epochs: 100 · Batch Size: 32
✦ Results
  • Accuracy: 86–88%
  • ROC-AUC Score: 0.87
  • Strong generalization on unseen customer data
  • Effective identification of high-risk churn customers
✦ Tech Stack
Python TensorFlow Keras Scikit-learn Pandas NumPy Matplotlib
