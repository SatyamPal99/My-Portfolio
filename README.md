# AI Engineer Portfolio Website

A modern, responsive, and interactive portfolio website designed to showcase professional experience, technical skills, academic achievements, and AI/Machine Learning projects. The portfolio features a futuristic dark-themed UI with smooth animations, interactive project modals, custom cursor effects, particle backgrounds, and responsive layouts.

## Features

### Professional Portfolio Sections

* Hero section with animated introduction
* About Me section
* Technical Skills showcase
* Professional Experience timeline
* Academic Projects showcase
* Education details
* Achievements and Certifications
* Contact section

### Interactive User Experience

* Smooth scrolling navigation
* Custom animated cursor
* Dynamic particle background
* Scroll progress indicator
* Hover animations and card effects
* Typewriter text animation
* Interactive project detail modals
* Responsive mobile navigation

### Project Showcase

* Context Aware Movie Recommender
* VC-Dimension Aware Sentiment Analysis
* Customer Churn Prediction using ANN

### Design Features
